Política de Privacidade

Este documento explica quais dados o site atture-adv coleta, para que servem e quais são os seus direitos sobre eles.

1. Quem é o controlador dos dados

O controlador dos dados tratados neste site é atture-adv, responsável por decidir como e por que esses dados são usados, nos termos da Lei nº 13.709/2018 (Lei Geral de Proteção de Dados Pessoais — LGPD). O canal de contato do encarregado pelo tratamento de dados é o e-mail .

2. Quais dados este site coleta

Este site coleta dados pessoais só quando você preenche o formulário de contato, de forma voluntária. Os dados são: nome, e-mail, WhatsApp, tamanho do escritório e o conteúdo da mensagem que você escreve.

Não coletamos nenhum outro dado pessoal seu além desses. Em especial, não pedimos CPF, não pedimos senha e não pedimos nenhum dado de processo pelo site.

3. Este site não usa cookie de rastreamento

Este site não usa cookie de rastreamento, não tem pixel de rede social (como o do Facebook/Meta ou do LinkedIn) e não usa nenhuma ferramenta de análise de tráfego de terceiro. Hoje não existe coleta de comportamento de navegação de quem visita o site. Se isso mudar um dia, esta política é atualizada antes da mudança entrar no ar.

4. Para que usamos os dados e a base legal

Usamos os dados do formulário de contato só para responder à sua mensagem e conversar sobre o produto atture-adv. A base legal é o art. 7º, inciso V, da LGPD — tratamento necessário para a execução de procedimentos preliminares relacionados a um contrato, a pedido do titular, já que é você quem inicia o contato pedindo para falarmos. Quando o uso do dado não decorrer diretamente de um pedido de contato seu, o tratamento também pode se apoiar no legítimo interesse (art. 7º, inciso IX, da LGPD), sempre limitado a essa mesma finalidade comercial e nunca para outro fim.

5. Com quem os dados são compartilhados

Os dados do formulário passam por dois tipos de fornecedor, estritamente para operar o envio da sua mensagem até nós: o provedor de e-mail que recebe o contato e o serviço técnico de envio de e-mail usado pelo site. Não vendemos, não cedemos e não compartilhamos seus dados com nenhum outro terceiro, e não os usamos para publicidade.

6. Por quanto tempo guardamos os dados

Guardamos o conteúdo do seu contato pelo tempo necessário para conduzir a conversa comercial e por um prazo razoável depois disso, para eventual retomada do assunto. Você pode pedir a exclusão a qualquer momento (veja a seção 8), e o dado é removido, salvo quando a lei exigir guarda por mais tempo.

7. Seus direitos como titular dos dados

Nos termos do art. 18 da LGPD, você tem direito a:

  • Confirmar se tratamos algum dado seu, e ter acesso a ele.
  • Corrigir dado incompleto, inexato ou desatualizado.
  • Pedir a anonimização, o bloqueio ou a eliminação de dado desnecessário, excessivo ou tratado fora do previsto nesta política.
  • Pedir a portabilidade dos seus dados a outro fornecedor, quando aplicável.
  • Pedir a eliminação dos dados tratados com base no seu consentimento.
  • Saber com quais entidades públicas ou privadas compartilhamos os seus dados.
  • Ser informado sobre a possibilidade de não fornecer o consentimento e sobre as consequências disso.
  • Revogar o seu consentimento a qualquer momento.

8. Como falar com a gente sobre os seus dados

Para exercer qualquer um desses direitos, ou para tirar qualquer dúvida sobre esta política, escreva para . Respondemos pelo mesmo canal.

9. Os dados de processos dos clientes do sistema não passam por este site

Este site é institucional: ele existe para apresentar o atture-adv, não para operar o sistema. Os dados de processos, publicações, autos e clientes tratados dentro do sistema atture-adv por um escritório contratante nunca passam por este site — eles ficam na instalação isolada daquele escritório, com o próprio escritório como controlador dos dados dos seus clientes e a atture-adv atuando como operadora. Esse tratamento é regido pelo contrato firmado entre o escritório e a atture-adv, não por esta política.

Podemos atualizar esta política quando o site ou a forma de tratamento de dados mudar. A data abaixo indica a versão vigente.
